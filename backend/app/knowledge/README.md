# Community Assistance Knowledge Graph

## Goal

The Community Helper Network should understand a user's needs expressed in natural language.

Instead of asking users to choose predefined categories like:

- Medicine
- Grocery
- Transport

the system should understand concepts from the user's request and recommend related services.

Example:

User:
"My father needs insulin."

The system should understand:

- Medicine
- Pharmacy
- Doctor
- Hospital

and recommend nearby helpers accordingly.
